# 宣传封面

沿用虾米伙伴系列封面的浅色网格底、侧边色条、左侧文字与右侧真实界面排版，配色采用模型工坊的青蓝色。

- [16:9 成品](../../docs/media/model-lab-cover.png)：1920 × 1080，供项目 README 和横版宣传使用。
- [可编辑版式](cover.html)：HTML/CSS 排版，标题和说明均为可编辑文字。
- [界面原图](model-lab-forecast.png)：2026-11-19 从[公开站点的销量预测案例](https://cherler.github.io/xiamimate-model-lab/#forecast)截取，保留原界面的模型、基线、范围与结果。

封面中的 M5 图表是已发布实验结果的回放。左侧九类业务介绍对应项目现有案例，不代表九类业务均优于基线；具体结果与限制以案例页为准。

## 更新方式

1. 修改 `cover.html` 中的标题、说明、标签或配色；需要新界面时替换 `model-lab-forecast.png`。
2. 在浏览器以 1920 × 1080 视口、1 倍像素比例打开 `cover.html`，等待字体和图片加载后导出截图。
3. 将成品保存为 `docs/media/model-lab-cover.png`，检查 README 中的图片显示与链接。

字体优先使用 PingFang SC；跨系统重新出图时需检查字体替换造成的换行变化。
