# 产品与设计计划

## 目标

帮助潜在客户检查定制推荐／预测系统的能力，并让学习者沿同一案例理解数据、算法、规则和交付。公开数据案例不能表述为真实客户案例。

2026-10-12 范围确认：只做模型能力与量化统计展示，暂不开发客户数据接入；后续执行顺序以 [展示站上线规划](launch-roadmap.md) 为准。下文保留早期产品设计背景。

第一至三轮真实训练与页面已完成。Ta Feng 新案例也已完成业务规格、协议冻结、训练和单次最终测试：见 [业务场景](evaluation/business-scenarios.md)、[评估协议](evaluation/evaluation-protocol.md)与[最终结果](tafeng-experiment-results.md)。Ta Feng 三任务现已接入页面并设为默认，UCI 第三轮保留为历史开发案例；见 [展示接入记录](showcase-iteration-1.md)。下文早期案例表保留最初规划背景。

## 两种深度

- 业务视角：业务目标、可操作结果、经营规则、效果证据、定制范围。
- 技术视角：数据切分、模型流程、实际执行逻辑、计划接入逻辑、评估和部署。

## 展示与事实

- 合成示例、真实回测、成本假设和业务实验使用独立状态。
- 概念图仍为设计示意；实际页面仅从完整实验读取指标，没有产物则显示未就绪。
- 推荐相对分数不是购买概率。当前关联理由来自已训练的商品相似度；探索加分规则单独说明。
- 未观测的商品不能简单当作明确负反馈；离线候选集和负采样方式进入报告。
- M5 销量与潜在需求不同；缺货情况下的需求不能凭空还原。
- 外部场景的提升不推广为任意客户收益。

## 视觉方向

- 画布：冷白 #F7FAFC；正文：海军蓝 #17324D。
- 操作：湖蓝 #087FA0；辅助选中：薄荷 #DDEDE6。
- 次级信息：钢蓝 #8397A6；预测对照：金色 #D3A343。
- 字体：系统中文无衬线，优先 PingFang SC；正文 12–15px、标题 26–32px，移动端自适应。
- 主结构：顶栏＋精简案例目录＋非等宽三栏工作台；购买历史 → 推荐列表 → 经营规则。
- 客户进入即可操作；证据位于操作下方。技术内容渐进展开。
- 设计检查：不以虚构大数字、均匀卡片墙、渐变横幅或聊天框充当产品主体。将视觉重点留给有输入输出的案例。
- 概念图右下附预测入口。真实页面展示可下载的实际离线指标。

## 分阶段验收

1. 独立原型（已完成）：主要导航、经营规则与视角切换可用；手机不溢出；需求只下载不发送。
2. 推荐真实闭环（本轮）：可重现数据清洗、时间切分、基线与候选、持久化评估报告、推理接口；结果不允许人工编写提升率。
3. 预测真实闭环（本轮）：双窗口回测、基线对比、按假设计算的补货情景；成本敏感性和更多窗口后续扩展。
4. 教学与接单：可运行课程实验、接口样例、部署交接材料；用户提供有效联系渠道后再接真实咨询。

## 范围

本轮根据新增需求实现真实数据下载、Python 训练、评估与推理服务。不创建付费资源、不发布站点、不改主站。暂无账号体系、在线支付、任意业务数据导入和真实线上实验流量。
