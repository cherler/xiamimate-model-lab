# UCI 案例静态化验收

2026-10-14 完成。目标为公开能力展示和教学回放，不新增客户数据接入、训练任务或线上效果声明。

## 交付范围

| 内容 | 本轮完成 |
| --- | --- |
| 推荐体验 | 原 24 位顾客＋新客、9 种方法、排除已购开关、0–100% 的 11 档探索、2–10 件显示数量；推荐理由和冷启动回退保留 |
| 预测体验 | 13 种逐日方法、36 个商品窗口／1,008 商品日；6 种周方法、144 个商品周；商品、起点、模型与库存情景交互 |

推荐参数组合为 25 × 9 × 2 × 11 = 4,950。每组保存 Top 20，页面按所选数量截取前缀；没有合成结果。仅支持已导出的公开样本与规则，不承诺任意新用户在线推理。切换规则不改变报告中的默认策略评估成绩。静态读取不显示为模型推理耗时；报告原 P95 是当时的本地排序测量。

## 操作

已有完整发布资源只需 Node.js 22+：

```sh
npm run dev                 # 5328，静态源目录
npm run build               # 校验各案例并生成 dist
npm run preview             # 5330，纯静态 dist
```

恢复原实验后重新导出与核验（需要 uv／Python 环境）：

```sh
npm run export:showcase
npm run export:uci
npm run verify:uci
```

`export:uci` 固定读取指定历史运行，不随 `artifacts/latest.json` 切换；版本目录按内容生成，失败不会替换清单。`verify:uci` 调用冻结模型复算同一演示输入，不训练或新开测试。原接口开发工具仍可通过 `npm run dev:api` 单独启动，展示页面不调用它。

构建所需其他案例资源沿用各自现有恢复流程；缺少时不能以重新训练已消耗的测试集补包。全站备份打包、完整版本回退演练与远程部署是后续任务，本轮不声称已完成。
