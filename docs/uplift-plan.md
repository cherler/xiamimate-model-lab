# 营销增量（Uplift）模型体系

更新：2026-10-28。首要目标是让潜在客户判断营销建模能力，不以模型名称数量或普通转化率替代增量证据。

## 业务与识别边界

输入为干预前特征、明确的可选动作、随机分配概率或可审计的分配机制、固定窗口结果。输出是“对谁采取哪个动作”的策略及相对于不干预的群体增量，而不是认定某个用户无干预一定不转化。个体两种潜在结果无法同时观测；高转化、券使用者、点击者都不能直接当作因果敏感人群。

先区分动作分配与实际曝光／领券／核销：主评估按随机分配的 ITT；不能把干预后的点击、核销或曝光当作干预前特征或直接筛掉未执行人群。观察数据的 DML／深网不能消除未记录混杂，缺少重叠时不支持相应人群动作推荐。

## 模型层级与选择

| 方法 | 实际含义与适用条件 | 首轮范围 |
| --- | --- | --- |
| Meta-Learner | 用分类／回归学习器估计处理效应的方法家族；不是独立于 X-Learner 的第六个模型 | S／T／X，统一 LightGBM 配置 |
| S-Learner | 将动作加入一个响应模型，再比较反事实输入；便宜，但模型可能忽略较弱动作信号 | 多动作、三目标分别拟合 |
| T-Learner | 各动作分别建响应模型；直接可解释，但小组方差大 | 同上 |
| X-Learner | 先估计响应，再拟合反事实伪效应并加权；可适应组间样本不平衡，不保证一定优胜 | 两种邮件分别对不发邮件，条件分配概率 1/2 |
| R-Learner | 使用折外结果预测与处理残差，以残差损失直接拟合异质效应 | LightGBM 加权伪结果回归；随机设计使用已知概率 |
| DML | 正交化与交叉拟合框架；最终效应可以线性、森林等，不等于两次回归自动有因果性 | 线性异质效应的残差回归自实现；不是完整 EconML 包复现 |
| DeepCausal Network | 泛称不足以指定网络；需要明确论文、结构与损失 | 用户确认按深度因果方向理解；候选 TARNet、Dragonnet |
| DESCN | Entire Space Network 联合建模分配与响应，X-network 学习中间伪效应；关注处理偏差、样本不平衡 | 后续按作者实现审计和复现；不能用普通 MLP 冒名 |

R-Learner 与 DML 共用残差化思想但不作同义词。随机试验中已知分配概率优先于盲目再拟合 propensity。TARNet 共享表示和不同结果头；Dragonnet 加入分配概率头／可选 targeted regularization；DESCN 的多任务学习不自动等于多营销目标或多动作联合优化。原 DESCN 论文主体是二元动作，需要单独验证多动作扩展。

## 首个主案例

Hillstrom 64,000 位近一年购买顾客，随机不发邮件／男装主题邮件／女装主题邮件，结果窗口两周。历史购买渠道是特征，不是随机选择短信、推送或邮件的实验。邮件主题不是用户性别，也不是逐 SKU 或优惠券匹配。

三项分别建模和报告的目标为访问、购买、销售额；主页面允许按其中一项圈选，同时观察另两项，不声称已完成联合多目标 Pareto 优化。销售额不是利润；成本与毛利率仅做明确假设的敏感性计算。低转化数量、销售额重尾、单次老实验和匿名行无法识别重复顾客均需展示。

固定协议见 `services/uplift/protocol.json`：60/20/20 按动作分层；仅训练分区拟合；验证集选择默认模型；保存全模型预测并冻结选择之后才评分测试集。相同预算比较随机触达、转化／响应排序、历史价值规则与 Uplift 排序；同时报告不干预参照、动作分配、分组结果和成对区间，保留负增益。测试结果一经打开，不再作为新独立测试反复选优。

## 全链路扩展：不是当前数据已经验证的能力

| 业务决策 | 额外数据与机制 | 候选方案 | 验收证据 |
| --- | --- | --- | --- |
| 人群圈选 | 无干预随机对照、覆盖范围、干预前快照 | X／R／DML、因果森林、DESCN | 同预算增量、分层校准、负效应与覆盖 |
| 渠道匹配 | 邮件／短信／Push／不触达随机动作、可达性、成本、权限 | 多动作 CATE＋预算约束策略 | 与最佳单渠道比较净增量、无动作比例和重叠 |
| 商品／券／红包匹配 | 可用候选、随机券面额、领取与核销分开、毛利和实际补贴 | 候选召回＋多动作效应／剂量响应＋分配优化 | 增量毛利减实际成本、补贴浪费、缺货／资格约束 |
| 时机与频次 | 多期状态、每次决策概率、退订、间隔、延迟转化 | 微随机试验、序列因果模型；后续才考虑离线策略学习 | 固定长期留出、跨期累计收益与退订、频控满足率 |
| 素材选择 | 随机素材曝光、版本、创意表示、相同预算 | 表征＋CATE／受控上下文 bandit | 素材增量而非点击率、探索流量、延迟奖励与 OPE |
| 持续度量 | 持久随机留出、固定归因窗、实际成本、用户级聚类和策略版本 | 分层 A/B＋DR／IPW 离线评估、漂移监测 | 增量成交／收入／毛利、置信区间；连续检验的预设规则 |

## 首轮结果与验收（2026-10-28）

固定训练／验证／留出人数为 38,400／12,800／12,800。默认模型在验证集 30% 触达名额下选定，下面只报告留出集相同名额、每千位候选顾客的估计。已知公开基准不是新活动前瞻验证。

| 圈选目标 | 验证集选定模型 | 相对不发邮件 [近似95%区间] | 相对响应排序 [近似95%区间] |
| --- | --- | --- | --- |
| 访问人数 | r | 18.28 [8.58, 27.98] | -0.94 [-10.33, 8.45] |
| 购买人数 | linear_dml | 1.41 [-0.84, 3.66] | 0.94 [-1.31, 3.19] |
| 销售额（美元） | linear_dml | 326.23 [-17.68, 670.14] | 80.20 [-432.27, 592.67] |

三个默认策略相对响应排序的区间均跨零，不能宣称因果模型已带来额外增益。访问目标相对不发邮件的增量有正向证据，但这不能证明 Uplift 优于简单圈选。购买与销售额目标的稀疏／重尾限制保留。响应排序和历史价值规则均完整展示；当前成对区间的主参照为响应排序，历史规则仅提供独立策略估计，未提供专门的成对差值区间。

页面包括目标／模型／名额切换、三目标交叉观察、动作分配、两动作排序曲线数值、预设人群支持量、12 条固定原序样本、成本与毛利假设敏感性。样本估计不等于真实个体标签。已运行方法在模型解读；TARNet、Dragonnet、DESCN 等未运行计划放在场景扩展。用户已确认 DeepCausal Network 按方向理解，不指定为某个确切架构。
